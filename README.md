# Personal Expense Tracker

A simple personal expense tracker built using Python, FastAPI, SQLite, HTML, CSS, and JavaScript.

## Features

- Add new expenses
- View recent transactions
- Track total spending
- View monthly spending
- Delete expenses

## Technologies Used

- Python
- FastAPI
- SQLite
- HTML
- CSS
- JavaScript

## How to Run

1. Clone or download this repository.
2. Install the required Python packages.
3. Run the application using Uvicorn.
4. Open the local URL shown in the terminal.

## Purpose

This project was created to practice Python, web development, APIs, and database integration.
